### 4\. XRD databases are a separate category

A database is not the same thing as an analysis program. Search-match software compares your measured pattern with reference information stored in a database.

| Database                            | What it contains                                     | Access                            |
| ----------------------------------- | ---------------------------------------------------- | --------------------------------- |
| PDF / Powder Diffraction File       | Reference powder diffraction patterns                | Commercial license                |
| ICSD                                | Inorganic crystal structures                         | Subscription / licensed           |
| COD                                 | Open crystal structure data                          | Free/open access                  |
| Materials Project                   | Computed materials properties and crystal structures | Free access with applicable terms |
| Crystallography Open Database (COD) | CIF structure files for many crystalline compounds   | Free/open access                  |
| CSD                                 | Organic and metal-organic crystal structures         | Commercial / institutional access |

A useful caution: a free database may not contain the same curated reference patterns or coverage as a commercial database. A CIF file from an open database also isn't automatically a validated reference powder pattern.

### 5\. Which ones should you prioritize for FC Cubic?

For your XRD pipeline work, I would start with this shortlist rather than attempting to learn every program.

1\. GSAS-II

Your main reference for a broad crystallographic workflow: importing patterns, indexing, refinement, outputs, project files, and scripting.

2\. FullProf and Profex

Useful independent implementations to compare refinement workflows, inputs, parameter settings, and output quality.

3\. HighScore Plus and TOPAS

Study these as commercial reference systems for phase identification, quantitative analysis, and advanced refinement. You don't necessarily need to purchase licenses to begin learning their concepts.

4\. VESTA and COD

Use them to understand CIF files, crystal structures, symmetry, and the connection between structural models and simulated diffraction patterns.

5\. Python scientific libraries

Learn NumPy, SciPy, Matplotlib, and pymatgen for understanding preprocessing, pattern comparison, reproducible analysis, and automation.

For QA, compare the tools using the same input dataset and record supported input formats, preprocessing options, scientific parameters, warnings, failure behavior, generated files, and numerical outputs. Different tools may legitimately produce different results because they use different algorithms, models, databases, and default settings.

Scope note: This is a broad directory of established and relevant software, not a literally exhaustive list of every XRD program, research code, or instrument-specific utility. License terms, versions, and commercial availability can change; confirm those with the official providers before choosing a tool.
